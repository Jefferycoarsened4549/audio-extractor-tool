Extracts the audio track from any video file and saves it as MP3, AAC, WAV, or FLAC. Processes without re-encoding when possible — extraction is instant for supported formats.

## Features

- Supports MP4, MKV, AVI, MOV, WEBM, and more
- Output to MP3, AAC, WAV, or FLAC
- Direct stream copy — instant extraction when format allows
- Batch extract from multiple video files
- Set MP3 bitrate: 128, 192, or 320 kbps

## FAQ

**How long does extraction take?**  
For MP3 from MP4, typically 10–30 seconds per hour of video. WAV copy is nearly instant.

**Does it work on YouTube downloads?**  
Yes — any video file on your PC works, regardless of where it came from.
